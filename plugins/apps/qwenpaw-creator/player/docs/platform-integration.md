# IVB 互动视频放映服务 · 平台对接说明

本文说明 IVB 放映服务对部署与调用链路的依赖,以及双方联调前的待确认项。服务侧的实现方式与平台侧的编排方式互不约束。

## 1. 服务概述

IVB 是互动视频放映服务:接收生产端导出的互动视频包,向用户放映,并按 (用户, 项目) 记录观看进度与上传归属。

- 服务不执行认证,不签发或校验凭据。
- 服务有状态:进度数据库与包体文件目录。

## 2. 对接需求

### 2.1 调用方身份

**需求**:每次请求需携带一个可代表已认证用户的标识,用于进度隔离与上传归属登记。

**约束**:该标识须由平台依据认证结果确定,终端用户不可自行指定或篡改。

**风险**:服务不验证身份来源。约束不满足时不会返回任何错误,表现为用户进度互相可见、可被覆盖、上传归属可被冒用。

**说明**:当前实现从 HTTP 请求头 `X-User-Id` 读取该标识。载体形式(请求头、签名令牌或其他)与字段名称均可按平台规范调整。

### 2.2 放映访问路径

**需求**:观众浏览器需访问服务读接口,获取包内容、视频分段与进度数据。

**约束**:服务需具备终端用户可达的访问入口。

**说明**:由于放映必须用户可达,仅将服务置于内网、由平台代理全部流量,并不能解决身份来源问题;身份注入需位于用户可达路径的入口层。入口形态由平台决定。

### 2.3 传输容量

**需求**:调用链路需支持以下两类请求。

| 场景 | 请求特征 | 实测数据 |
|---|---|---|
| 包上传 | 单次请求体为完整视频包(多段成片打包) | 约 136 MB,随内容时长增长 |
| 视频播放 | HTTP Range 分段请求,响应 `206 Partial Content` | 单段 12–28 MB,全分支合计 9–10 分钟 |

**说明**:若链路对请求体大小、请求超时或分段响应缓冲存在限制,请反馈。服务侧可调整上传方式,例如改由平台存储、服务侧拉取并登记。

### 2.4 对外访问地址

**需求**:部署完成后,平台需向生产端提供放映服务的对外可访问 base URL。生产端在用户发布包成功后,要用它生成给用户点击的放映链接。

**约束**:该 base 与服务内部监听地址通常不一致(例如经网关挂载、或挂在子路径下)。两个值的消费方不同:

| 值 | 消费方 | 用途 |
|---|---|---|
| 服务挂载的子路径 | 服务侧 | 解析页面内资源路径,服务侧已有配置项承接 |
| 对外可访问的 base URL | 生产端 | 拼接展示给用户的放映链接 |

**说明**:该 base 一旦变更,此前发出的放映链接即失效,请平台确认其稳定性。若存在测试 / 预发 / 生产多套环境,请分别提供,并说明由谁在何时交付给生产端。

## 3. 部署相关约束

服务当前为单实例设计,存储形态如下。

| 项 | 事实 |
|---|---|
| 进度库 | SQLite,单写者,不支持多副本并发写 |
| 日志模式 | WAL,依赖本机文件锁,不支持网络文件系统 |
| 包体 | 本地目录 `bundles/{project_id}/` |
| 持久化 | 进度库与包体需位于同一持久化存储,容器重建后仍需保留 |

**待确认**:平台部署规范是否允许"单副本 + 持久存储"。若要求多副本,服务需先完成存储改造(进度库迁移 PostgreSQL、包体迁移对象存储),改造完成前不具备多副本部署条件。

## 4. 联调验证项

上线前建议共同验证以下几项,用于确认 §2.1、§2.3 与 §2.4 成立。

| # | 验证内容 | 预期结果 |
|---|---|---|
| 1 | 两个不同用户分别读取同一项目的进度 | 互不可见 |
| 2 | 由终端用户构造自称他人的请求 | 服务收到的身份仍为真实认证用户 |
| 3 | 上传真实体量的包 | 请求成功,无 413 / 504 |
| 4 | 播放中拖动进度条 | 分段请求正常,响应未被整体缓冲 |
| 5 | 从生产端点击发布成功后返回的放映链接 | 能打开对应项目,页面内资源无 404 |

第 2 项不通过时,双方再确定身份传递方案(增加签名校验,或改为平台侧代理调用)。

## 5. 服务侧可适配项

| 平台条件 | 服务侧适配 |
|---|---|
| 身份标识载体不是请求头 | 改为读取约定字段 |
| 身份以平台签名凭据传递 | 增加验签逻辑 |
| 提供标准大文件上传通道 | 改为平台存储 + 服务侧拉取登记 |
| 要求多副本部署 | 先完成 PostgreSQL 与对象存储改造 |
| 需挂载于子路径 | 已支持,通过 root path 配置 |
| 由平台侧统一代理调用 | 已支持,接口不依赖浏览器直连 |

## 6. 服务范围

以下能力不在服务范围内:登录与凭据签发、细粒度权限模型(仅提供"我的 / 全部"两种列表视图)、内容审核、视频转码、平台用户体系集成(仅使用平台传入的单一标识值)。

## 7. 待平台确认

1. 是否允许单副本 + 持久存储的部署形态(§3)。
2. 用户身份以何种机制传递至服务(§2.1)。
3. 调用链路对 136 MB 请求体与 Range 分段响应的限制情况(§2.3)。
4. 部署后由谁、以何种形式向生产端交付对外 base URL,及其稳定性承诺(§2.4)。
