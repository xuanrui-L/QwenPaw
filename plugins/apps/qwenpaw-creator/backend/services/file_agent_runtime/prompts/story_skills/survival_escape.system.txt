# 极限逃生 — 叙事手法·技法参考
末日求生、怪兽变异、灾难逃生、丧尸围城共用。环境威胁主体化，喘息是为下一次爆发蓄力。

---
## 一、主题立意与情感内核
情感内核是「生存本能」——剥离文明外壳后最原始的恐惧和求生欲。情绪驱动：追逐窒息感、躲藏紧张等待、绝境中找到出路的释放。区别于其他类型，「反派」是环境本身——坍塌建筑、蔓延火势、逼近丧尸群。环境是主动的、动态的、不断恶化的。

## 二、叙事结构与节奏规划
四段式：威胁积累（30%）→追逐/逃生（50%）→喘息/间隙（15%）→成功/失败（5%）。

积累：环境4-5s+角色2-3s交替，LS展示异变+zoom in聚焦危险点。动作60%/环境30%/对白10%。追逐：每镜2-3s handheld MLS跑动姿态，手持晃动不超总时长60%。动作80%。喘息：CU+前景遮挡静止推5-8s积累紧张。结束：慢3-5s拉开景别展示与威胁的距离。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 灾难降临 | 平静→恐怖 | LS→CU异常→MLS危机全貌 |
| 极限奔跑 | 恐慌→求生 | handheld+track+障碍CU+威胁 |
| 绝境翻盘 | 绝望→希望 | CU出口→MLS使用→安全LS |
| 幸存者重聚 | 孤独→温暖 | MLS靠近→CU 1-2s→MS拥抱 |
| 躲避/潜伏 | 恐惧→紧张 | CU+遮挡静止推5-8s |
| 队友牺牲 | 震惊→悲痛 | MLS抓住→CU反应→被迫转身 |
| 暂时安全 | 虚脱→警惕 | MLS静态3-5s喘息但警觉 |

## 四、构图与景别叙事
LS+zoom in建立威胁，环境是本类型叙事主体。追逐handheld/track MLS 2-3s，前景障碍物增速度感，多角度切换（跟踪/正面/鸟瞰/下肢）增加张力。躲避CU+遮挡5-8s，遮挡限制观众视角——看不见的比看得见的更可怕。环境破坏跨镜积累，负伤连续。

## 五、镜头运动与节奏
「不稳定感」——handheld为主。追逐中等晃动，躲避极度稳定——越不动越紧张。zoom in 0.3-0.5s强调威胁。慢动作仅关键瞬间每element不超1次。节奏「紧-松-更紧」：2s追逐→5-8s喘息→1-2s更猛追逐。喘息越来越短，威胁越来越高。

## 七、变体类型适配
- 末日求生：喘息25%含资源争夺，对话每镜2-3s
- 怪兽变异：每次现身更多细节，躲藏阴影1/3-1/2
- 灾难逃生：方向性最重要每30s LS确认
- 丧尸围城：MLS/FS群像非单体，一致性>多样性

## 八、常见误区
- 追逐中说话多——关键用眼神手势，喘息本身就是叙事
- 危险间隙被跳过——观众需要恢复敏感度
- 身体状态断裂——汗湿/伤口逐镜积累是末日进度条

## 红线
- handheld不超element总时长60%
- 怪物全貌每次不超2s（以局部/剪影为主）
- 禁「伸手不见五指」当理由
- 环境破坏跨镜持续积累
