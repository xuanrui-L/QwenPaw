# 现代言情 — 叙事手法·技法参考
现代甜宠、霸总甜宠、家庭伦理共用。近景/特写驱动，表情细节优先，留白式节奏。

---
## 一、主题立意与情感内核
情感内核是「关系的距离变化」——从陌生到靠近、误会到理解、抗拒到接纳。情绪驱动：暧昧张力、甜蜜确认、冲突刺痛、和解释然。区别于强情节类型，现代言情依靠微表情、肢体语言和停顿中的暗流推动叙事，情感真实度是唯一标准。

## 二、叙事结构与节奏规划
四段式：铺垫（40%）→冲突累积期（30%）→收束余韵期（30%）。

铺垫：每镜4-6s MS建立空间→MCU对话→CU收束情绪，对白为主穿插反应。冲突：对切加速2-3s，景别MS→CU收紧，越激烈剪辑越快。收束：拉开MS/MLS留1-2s静默镜，拥抱等情感落点维持3s以上不切。对白70%/动作30%。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 初遇/重逢 | 好奇→心动 | LS→慢推CU，2-3s停顿酝酿情感 |
| 暧昧/试探 | 紧张→期待 | MCU对切，反应拉长0.5s |
| 表白/确认 | 忐忑→幸福 | MS同框→CU说话人→反应人 |
| 误会/争吵 | 愤怒→受伤 | 对切加速2s+过肩收紧 |
| 分离/思念 | 孤独→隐忍 | CU slow push in+手部小动作 |
| 和好/拥抱 | 释然→温暖 | CU各自→MLS拥抱3s+ |
| 危机/保护 | 担忧→坚定 | 过肩→快对切后MS收束 |

## 四、构图与景别叙事
MCU/CU正反打，说话人CU/反应人MCU交替2-3轮换景。弱势俯视强势仰视。情绪高点push in 2-3s同步缩短情感距离。亲密细节特写（手触碰/眼神交汇）静态或极缓handheld。服装跨element不变，道具每次一致。

## 五、镜头运动与节奏
静态和极缓为主。固定正反打，情绪积累slow push in 2-3s。亲密极缓handheld模拟呼吸感。冲突对切加速但运镜不剧烈——激烈感来自剪辑节奏。禁360° orbit和激烈推拉。

## 七、变体类型适配
- 甜宠：冲突15%暧昧35%，push in 3-4s，误会不超2轮
- 家庭伦理：对白80%，冲突通过同景别内距离变化暗示

## 八、常见误区
- 冲突变争吵——真正冲突在沉默中产生，各看不同方向更有张力
- 连续CU对切——每2-3轮切MS/MLS刷新空间
- 情感线缺视觉落点——物品/手势/位置锚定变化

## 红线
- 禁过度戏剧化运镜（激烈推拉/360° orbit）
- 吻戏只用「靠近/拥抱/凝视」
- 不得连续3镜同景别同角度（对话对切除外）
