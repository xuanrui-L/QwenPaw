# 硬核武打 — 叙事手法·技法参考
武术功夫、古装打戏、冷兵器对决、帮派械斗共用。连招连贯优先，蓄力→交锋→定胜负三段式，动作即是叙事。

---
## 一、主题立意与情感内核
情感内核是「通过身体表达意志」——每次出拳、格挡、呼吸调整都是内心状态外化。情绪驱动：对手间试探的紧张感、招式碰撞的力量对抗、胜负揭晓的戏剧性。区别于仙侠法术对轰，硬核武打魅力在于「物理感」——力量有来源、动作有准备、结果有代价。好的武打不需要台词解释。

## 二、叙事结构与节奏规划
四段式：对峙蓄力（30%）→交锋期（50%）→定胜负（10%）→余韵（10%）。

蓄力：每镜3-5s CU眼神/站姿/呼吸交替，push in强调聚焦，动作70%/环境20%/对白10%。交锋：每镜1-2s MLS/MS连招动作track跟随，每招1-2s，动作95%。连招阶段不插CU反应——保持动作连续性。定胜负：slow motion 2-3s+收势2s，每element最多1次不超3s。余韵：MLS 2-3s展示双方姿态和呼吸节奏。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 高手对峙 | 紧张→试探 | MLS同框分立→CU表情2-3轮先以气场分高下 |
| 兵器相击 | 碰撞→角力 | MS/MCU接触点1s停顿后弹开 |
| 必杀技 | 蓄力→释放 | CU蓄力→MLS施展→CU效果→对手反应 |
| 战后收刀 | 疲惫→肃穆 | MLS收势→CU手颤抖→拉开反应 |
| 围殴/混战 | 混乱→敏捷 | handheld跟随主角1-2s换对手 |
| 师徒传承 | 恭敬→继承 | MLS同框→CU细节→拉开全景 |
| 比武擂台 | 荣誉→胜负 | MLS擂台→观众反应→关键一击 |

## 四、构图与景别叙事
MLS是基础景别——保持动作完整可见，不可因贪近景丢失连续性。蓄力push in聚焦，交锋track/pan，关键一击MLS→CU→slow motion。CU接触点是slow motion落点而非起点。兵器跨镜一致，环境各shot一致，战损连续积累。

## 五、镜头运动与节奏
三段式：蓄力慢推/固定，交锋track/pan同步动作，定胜负slow motion。track需与角色动作同步，pan匹配出招节奏。handheld只用于混战和地面缠斗。慢动作后紧跟正常速度反应镜确认结果。三原则：蓄力越慢越好，交锋越快越连贯，收势留时间让结果落下。

## 七、变体类型适配
- 冷兵器：兵器CU 20%接触0.5-1s停顿，断裂/脱手每element最多1次
- 帮派械斗：开场LS展示场地人数，主角MLS为锚点
- 武术功夫：对峙蓄力40%，起手式/步伐有叙事意义

## 八、常见误区
- 用快切掩盖动作不足——每招在MLS清晰可见
- CU过多——每3个MLS插1个CU最优
- 忽略收势——胜利者风度失败者尊严

## 红线
- 仅关键一击1次slow motion不超3s
- 连招阶段不插CU反应
- 禁血肉横飞/断肢
- 每次交锋前必须有蓄力铺垫
