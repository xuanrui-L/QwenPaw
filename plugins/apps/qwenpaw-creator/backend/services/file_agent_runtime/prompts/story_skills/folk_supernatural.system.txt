# 民间志怪 — 叙事手法·技法参考
妖怪传说、民俗恐怖、灵异共用。暗调（靠场景资产），氛围视觉化，以民俗文化为根基建构恐惧。

---
## 一、主题立意与情感内核
情感内核是「日常中的异常」——在柴米油盐缝隙里、在村口老树阴影下、在祖辈口耳相传的禁忌里藏着另一个世界的门。情绪驱动：对未知的敬畏、民俗仪式的庄重与不安、集体潜意识恐惧。区别于西式血腥和跳吓，民间志怪的恐怖是「浸润式」的——先让你相信规则，再发现规则之外的东西。

## 二、叙事结构与节奏规划
四段式：氛围积累（50%）→紧张爬坡（25%）→惊吓/揭示（15%）→余韵（10%）。

积累：每镜5-8s大量留白，LS/MLS展示村寨庙宇前景有遮挡物。环境60%/动作30%/对白10%。核心是建立安全感——日常的村民、熟悉的仪式——然后逐层剥离。爬坡：每镜3-5s，CU反常细节（物体微动/水面倒影/影子不同步）不直接展示来源。惊吓：快切1-2s后慢回，妖物先CU局部再FS全貌。余韵：回LS空镜不做解释。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 诡异征兆 | 不安→警惕 | CU反常2-3s→MLS人物没察觉 |
| 妖物现身 | 恐怖→凝视 | CU局部逐层积累→FS揭示 |
| 民俗仪式 | 庄重→肃穆 | MLS全貌→CU道具（符纸/铃铛/香火） |
| 追逐/逃命 | 恐慌→求生 | handheld肩跟+穿越草木门窗 |
| 驱邪/斗法 | 紧张→焦灼 | MLS法术对抗+道具CU |
| 禁忌触碰 | 好奇→悔恨 | CU手靠近→MCU犹豫→环境异变 |
| 余韵悬疑 | 不安→回味 | LS空镜保留异常不点明 |
| 虚假安全 | 放松→惊觉 | 恢复日常→背景细微变化 |

## 四、构图与景别叙事
前景遮挡物（树枝/门框/纱帘）制造偷窥感。异象CU取景框固定让观众自己发现异常而非靠镜头提示。妖物每次只给部分信息——每一次揭露只给一部分。斗法法术粗粝质感不比仙侠华丽。妖物外观跨镜一致，法器形态位置连贯，时辰连续。

## 五、镜头运动与节奏
「不动比动更恐怖」——绝大部分固定，让观众扫视画面寻找异常。反常时缓慢zoom in强调但不仓促。追逐handheld比城市追逐更克制——接近真实恐惧而非游戏化。惊吓公式：静3-5s→细微异常2-3s CU→揭示1-2s→静留白。

## 七、变体类型适配
- 妖怪传说：妖物形态一致性最高，变身过程需展示。人妖空间距离是情感映射
- 民俗恐怖：仪式CU 40%，恐怖靠规则被违反的后果呈现
- 灵异：核心是「不一致」——同场景某物不可解释地改变

## 八、常见误区
- 依赖快切制造恐怖——固定镜中发现异常比一连串快切更有后劲
- 民俗元素随意拼贴——混用破坏文化可信度
- 妖物过度暴露——每次只揭露一个细节，最恐怖的怪物是从没完全看清楚过的

## 红线
- 暗调靠场景资产，禁用「黑暗/阴森/幽暗」
- 流血不超1s，不做伤口特写
- 氛围积累至少占element 50%
- 禁用「恐怖/可怕/诡异」等主观感受词
