# 萌宝家庭 — 叙事手法·技法参考
单亲带娃、萌宝助攻父母感情、家庭亲情共用。儿童视角低机位，温情是叙事底色而非点缀。

---
## 一、主题立意与情感内核
情感内核是「无条件」——父母对孩子的无条件付出、孩子对父母的无限信任、家庭在困境中相互支撑。情绪驱动：亲子互动带来的治愈感、儿童天真视角解构成人世界的错位幽默、危机化解后的温暖回归。儿童的视角是这类叙事的独特资产——通过孩子的眼睛让平常事物重新变得新鲜动人。

## 二、叙事结构与节奏规划
三段式：日常温馨（60%）→冲突/委屈（20%）→感动/和解（20%）。

日常温馨：每镜3-5s，MS/CU自然交替。儿童视角机位高度与视线平齐，MLS双人同框展示牵手/抱/喂饭等互动。动作/状态60%/对白30%/环境10%。冲突：CU表情为主每镜2-4s，不过度剪辑，哭泣不超3s。和解：MS→CU慢推留2-3s静默镜，MS一家同框3-5s静态或极缓push in留给情感余韵。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 萌宝初登场 | 期待→喜爱 | LS环境建立→低机位MLS展示宝宝在全景中的位置 |
| 亲子互动 | 温暖→甜蜜 | MLS双人同框3s→CU各自表情交替 |
| 宝宝助攻 | 天真→感动 | CU宝宝→大人反应CU→MS两人同框 |
| 委屈/哭泣 | 伤心→心疼 | CU宝宝表情2-3s后切安慰动作 |
| 家庭危机 | 紧张→担忧 | MS分离感+CU表情交替 |
| 温暖收束 | 感动→治愈 | MS一家同框3-5s静态或极缓push in |
| 成长瞬间 | 惊喜→骄傲 | CU宝宝完成小成就→家人反应 |

## 四、构图与景别叙事
低机位约60cm是标志性视觉特征。MLS双人同框展示互动，MS单人表情交替。保持成人与儿童身高差异自然合理，禁止镜头扭曲真实比例。大量CU家庭元素（玩具/餐具/照片）。儿童服装发型跨镜一致，家庭环境布局各shot逻辑统一。

## 五、镜头运动与节奏
「柔软」——缓慢平稳，静态镜头占主体。slow push in用于情感升温，极缓pan建立家庭空间。低机位跟拍用匹配儿童速度的缓慢track。3-5s每镜为基准，冲突不高于2-4s，温暖收束敢于留白——3s以上静态给观众情感沉降时间。

## 七、变体类型适配
- 单亲带娃：成人镜头占比40%，快切与亲子慢镜形成反差
- 萌宝助攻感情：宝宝视角30%，转折全部通过宝宝参与视觉化
- 多代同堂：空镜15%，老物件承担叙事功能，群像调度展示权力结构

## 八、常见误区
- 儿童角色被当搞笑工具——反应须符合年龄，萌点天然不是演出来的
- 过度使用儿童CU——时长应比成人短（1-2s），同框时平衡景别
- 冲突戏剧化高于真实感——真实小摩擦胜过编造大冲突

## 红线
- 禁止成人与儿童身高差被镜头扭曲
- 儿童哭泣/受伤不超3s
- 温暖氛围靠场景参考图，禁用「暖色/温馨」词汇
- 儿童行为不超出年龄段
