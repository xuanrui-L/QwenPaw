# 古装仙侠 — 叙事手法·技法参考
仙侠修真、穿越古装、古风甜宠共用。全景建立世界，法术/轻功需运镜空间，服化道一致性优先。

---
## 一、主题立意与情感内核
情感内核在于「超越」——超越凡躯局限、超越天命束缚、超越时间的等待。情绪驱动：修行孤独与坚持、飞升释然与悲壮、千年等待与重逢。叙事核心是「道心」——角色每个选择中对道心的坚守或动摇。世界宏大与情感细腻并存。

## 二、叙事结构与节奏规划
三幕式：文戏铺垫（50-60%）→打斗/施法（25-35%）→世界揭示（10-15%）。

文戏：MS/CU每镜3-5s深度对话和情绪积累，空镜做情绪呼吸安排在段落切换处。对白50%/动作40%/空镜10%。打斗：三段式——蓄力慢CU眼神/手势2-3s→交锋快MLS 1-2s→收势慢FS 2-3s。法术释放zoom in至CU手部/法器强调凝聚。世界揭示：LS/VLS空镜3-5s段落间节奏锚点。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 秘境初现 | 敬畏→惊叹 | LS慢推3s+角色CU人景交替 |
| 功法觉醒 | 压抑→爆发 | FS粒子扩散+boom up |
| 御剑飞行 | 自由→畅快 | track/arc环绕MLS面部可见 |
| 战场对峙 | 紧张→决绝 | MLS对称+CU蓄力2-3轮爆发 |
| 生离死别 | 悲恸→隐忍 | CU slow push in留2-3s静默 |
| 千载重逢 | 恍惚→释然 | MS同框不急于切近景 |
| 渡劫飞升 | 艰难→超脱 | VLS→MLS考验→FS飞升+boom up |

## 四、构图与景别叙事
LS/VLS+slow pull back/boom up强调空间尺度。对话MS/MCU+前景虚化（纱幔/雕花窗）增加层次。打斗FS/MLS+track/arc。情绪CU push in。朝代服饰跨element严格一致，法器形态发光统一，天气连续。

## 五、镜头运动与节奏
凡间固定/缓pan强调人间烟火，仙境运动更多——slow pull back揭示全貌、boom up飞升、arc环绕、track跟随。法术节奏：蓄力CU→释放zoom in/track→效果pull back/boom up。打斗三段式核心。空镜静止/极缓pan 3-5s沉浸。

## 七、变体类型适配
- 穿越古装：增加视觉反差，古装/现代装element间切换
- 古风甜宠：打斗降至15%以下文戏65%，空镜花卉山水

## 八、常见误区
- 空镜过多——每2-3叙事插1空镜，每个须有叙事功能
- 打斗频繁切换——交锋MLS为基准仅关键动作切CU
- 法力堆砌——发光不超prompt 15%，须有蓄力和目标

## 红线
- 禁跨朝代混搭（除非剧情设定）
- 法术描述不超prompt总长20%
- 禁写具体法术名称/口诀原文
- 不得连续3镜同景别（文戏对话除外）
