# 喜剧搞笑 — 叙事手法·技法参考
纯搞笑、穿越梗反差、无厘头共用。快切服务笑点节奏，可打破第四面墙，笑点密度是核心指标。

---
## 一、主题立意与情感内核
情感内核是「预期违背」——让观众在一个方向准备好，然后突然转向另一个方向。情绪驱动：笑点释放的意外感和畅快感、角色陷入荒谬困境的愉悦。区别于其他类型追求沉浸感，喜剧追求精确计算的节奏感——铺垫长度、释放方式、笑点间隔都是设计好的。

## 二、叙事结构与节奏规划
四段式：铺垫/情境建立（30%）→笑点铺垫释放（40%）→叠加（20%）→收束（10%）。

铺垫：MS/MLS正常节奏3-5s，重点让观众理解情境规则——规则越清晰违背越好笑。释放：铺垫2-3s→释放1-2s→反应1-2s。语言类对白60%/动作30%/反应10%。肢体类动作70%/反应20%/对白10%。叠加：连续2-3个快速反应镜0.5-1.5s，用信息轰炸升级笑果。收束：重新拉回正常节奏。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 打脸/flag回收 | 自信→打脸 | CU立flag→同角度反转打脸强调对比 |
| 误会被当场揭穿 | 紧张→尴尬 | 正反打加速→指认CU 1s→FS全景尴尬 |
| 肢体摔倒 | 正常→意外 | MLS全程→CU表情→周围人反应三连环 |
| 反差出场 | 期待→意外 | LS剪影→zoom out揭示搞笑装扮 |
| 冷幽默/吐槽 | 严肃→滑稽 | MCU说荒谬话→反应人面无表情→全景 |
| 追逐打闹 | 慌乱→滑稽 | MLS/FS全程+障碍物互动 |
| 温情收束 | 搞笑→温暖 | 节奏恢复MS同框收情感线 |

## 四、构图与景别叙事
肢体用FS/MLS全景展示全身动作——观众需要看到全身才会感知失衡和滑稽。表情CU快速捕捉1-2s，停留比正剧短。快切0.5-1.5s叠加反应角度。打破第四面墙用zoom in强调。夸张幅度同element一致，道具跨镜连续。

## 五、镜头运动与节奏
「稳中出奇」——固定镜头建立情境，笑点释放时用运动镜头。zoom in强调夸张表情，fast zoom用于反转打脸。静态中的突然zoom in本身就是喜剧语汇。节奏：铺垫慢→释放快→反应快→叠加更快。

## 七、变体类型适配
- 纯搞笑/无厘头：肢体70% MLS为主，打破第四面墙2-3次/element
- 语言类：正反打80% G眼给说话人，铺垫1.5-2s释放0.5-1s
- 穿越梗反差：古今对比镜，现代元素每element最多2镜不超1.5s

## 八、常见误区
- 铺垫不足——需2-3s建立预期，越低的笑料越需要正式铺垫
- 不留呼吸空间——收束过渡至少10%，快慢结合才有效
- 快节奏等于好笑——快切服务于内容而非代替内容

## 红线
- 禁恶意贬低性肢体搞笑（打脸/摔跤不超2s）
- 穿越梗现代元素每element不超2次
- 单element不连续3镜同类型笑点
- 喜剧效果来自情境节奏，非prompt写「好笑」
