# 年代怀旧 — 叙事手法·技法参考
民国风云、70-90年代怀旧、知青时代共用。年代服化道一致性极高，以物喻情。

---
## 一、主题立意与情感内核
情感内核是「时间中的不变」——在翻天覆地变迁中，人与人情感、对故土眷恋、对理想的坚持才是核心。情绪驱动：怀旧温暖与失落、时代洪流中个体无力感、人情味。在年代叙事中「物」比「人」更能承载分量——旧衣裳、泛黄照片、搪瓷缸都是情感锚点。

## 二、叙事结构与节奏规划
四段式：时代氛围（20%）→人物日常（40%）→冲突/爆发（30%）→余韵（10%）。

氛围：LS/VLS空镜展示年代地标/街道4-6s，静止或极缓pan——既是背景更是情感容器。日常：每镜3-5s MS/CU交替，大量CU年代细节，动作60%/对白30%/空镜10%。爆发：加速2-4s CU为主MCU留白，对白50%/动作40%/环境10%。余韵：LS空镜或MLS剪影让情绪在环境中沉降。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 时代全景 | 沉浸→代入 | VLS/LS空镜4-6s展示地标人群 |
| 离别/重逢 | 不舍→悲喜 | MS同框2-3s→CU识别→动作 |
| 时代冲突 | 对抗→无力 | 过肩+时代符号（标语/制服） |
| 回忆闪回 | 恍惚→伤感 | 叠化，闪回松当前紧 |
| 生活日常 | 温暖→质朴 | MS劳作+CU年代道具 |
| 时代变革 | 冲击→适应 | LS面貌变化→MS面对新事物 |
| 多年重聚 | 沧桑→释然 | CU岁月→MS相视→LS收尾 |

## 四、构图与景别叙事
LS/VLS空镜静止或极缓pan让环境成为叙事部分。日常MS跟随动作穿插CU细节（搪瓷缸/自行车/缝纫机/照片）不做快速切换。情感MCU正反打留白——角色克制比爆发更有力量。时代跨越叠化过渡。服化道跨element严格一致。

## 五、镜头运动与节奏
「稳和缓」——静止为主，pan/track偏慢，与时代节奏匹配。叠化是核心过渡手法，闪回出入留1s过渡。每2-3叙事镜可插一细节空镜。空镜是情感呼吸的重要语汇。

## 七、变体类型适配
- 民国风云：冲突35%加速1.5-3s，时代符号空镜每element至少2镜
- 70-90年代：生活空镜25%日常轻快，收束老照片CU叠化
- 知青时代：自然空镜30% LS/VLS强化渺小感，对白最少20%

## 八、常见误区
- 用对白解释时代——一个搪瓷缸抵百句「这是八十年代」
- 年代符号过度堆砌——每场景1-2个核心元素即可

## 红线
- 禁不同年代元素混入同一场景
- 暖黄/复古色调靠场景图，禁用色调词
- 当代行为不出现在年代剧中
- 年代标志物视觉一致性和时间准确性是硬约束
