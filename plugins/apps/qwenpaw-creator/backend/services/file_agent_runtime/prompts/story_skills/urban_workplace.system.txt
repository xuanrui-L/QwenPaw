# 都市职场 — 叙事手法·技法参考
纯职场、商战共用。空间关系表达权力，谈判/对峙的景别节奏是叙事核心。

---
## 一、主题立意与情感内核
情感内核是「权力博弈」——沉默、停顿、谁先移开视线都是没有硝烟的战斗。情绪驱动：不安全感、占上风时满足、尊严受挑战的反击。商战职场关键是把事说清楚——观众从理解局势和预判策略中获得智力满足。

## 二、叙事结构与节奏规划
四段式：常态办公（60%）→谈判/冲突（20%）→压力/内心戏（10%）→收束/决策（10%）。

办公：每镜3-5s对切+MS单人建立关系，对白70%/微动作20%/环境10%。谈判：加速对切2-3s景别MS→MCU→CU收紧，高位仰视低位俯视。内心：CU面部push in或手部小动作（转笔/敲桌面）。收束：拉开MS/MLS，反转以动作反应为主。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 空降/入职 | 陌生→观察 | LS→MLS track→MCU对视 |
| 谈判对峙 | 紧张→角力 | 正反打加速景别收窄，CU留1s沉默 |
| 职场霸凌 | 压抑→隐忍 | 俯角MS+过肩强化占据 |
| 逆风翻盘 | 压抑→酣畅 | CU证据→反应人→MS逆转 |
| 私下施压 | 威胁→不安 | MCU过肩前景肩膀挤压空间 |
| 酒后真言 | 放松→脆弱 | MS/CU交替稍慢 |
| 辞职/告别 | 释然→解脱 | MS整理→LS背影 |

## 四、构图与景别叙事
MCU过肩对切。高位仰视权威低位俯视弱势。白热化时景别收窄加快cut。独自思考CU手部小动作比表情更真实暴露焦虑。走廊track侧跟MLS双人同框不切碎空间。着装跨element一致，布局各shot统一。

## 五、镜头运动与节奏
「稳重」——固定正反打是基础。谈判加速收景别而非依赖运动。权力展示用缓慢zoom in——掌握话语权时缓缓推近。越激烈景别越紧剪辑越快，但每CU后留沉默空间让观众读到表情信息。

## 七、变体类型适配
- 纯职场：常态70%，会议MS环拍两轮后对切
- 商战：谈判35%景别收窄加快，数据通过CU看文件具象化

## 八、常见误区
- 谈判依赖台词——最精彩在台词停止时开始
- 权力关系靠对白——坐/站/空间占比需镜头呈现
- 办公空间逻辑不一致——工位/窗/门各shot一致

## 红线
- 禁logo/品牌明确展示
- 屏幕内容不写具体文字
- 不得连续5镜同景别对切
