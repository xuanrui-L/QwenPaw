# 悬疑惊悚 — 叙事手法·技法参考
悬疑、惊悚、心理博弈共用。信息控制镜头（遮挡/局部/过肩），反转的剪辑点是叙事核心。

---
## 一、主题立意与情感内核
情感内核是「不确定性的焦虑」——观众比角色知道得更少（或更多）时产生的不安感。叙事核心是「信息的分配」——什么给观众、什么不给、什么时候给。好的悬疑让观众主动参与解码而非被动接收惊慌。心理博弈靠眼神停留、沉默长度、细微表情颠覆认知。

## 二、叙事结构与节奏规划
四段式：铺垫积累（50-60%）→紧张爬坡（20-30%）→释放/反转（10-15%）→余韵（5-10%）。

铺垫：每镜5-8s，中长焦过肩/遮挡前景（门框/纱帘/书架），角色在景深中移动。动作40%/环境40%/对白20%。关键让观众习惯环境建立安全感——然后逐层剥离。爬坡：微加速每镜缩短0.5-1s前景遮挡增加。释放：快切0.5-1s后慢回，静态2-3s→突发动作。余韵：1-2镜不做解释。

## 三、分场景情绪设计
| 段落类型 | 情绪方向 | 叙事手法 |
|---|---|---|
| 发现线索 | 疑惑→警觉 | CU手靠近→MCU表情变化交替 |
| 追逐/躲避 | 恐慌→求生 | handheld肩跟不展示全貌 |
| 身份反转 | 震惊→重构 | 正反打加速→台词后留CU 1-2s |
| 真凶暴露 | 积累→揭示 | CU细节逐层→FS揭示 |
| 心理对峙 | 紧张→试探 | MCU过肩对切留沉默 |
| 虚假安全 | 松弛→不安 | 恢复MS→细微异常 |
| 最终真相 | 颠覆→释然 | CU细节留2-3s拼图 |

## 四、构图与景别叙事
前景遮挡占1/3-1/4制造偷窥。不以全知视角展示空间——观众应有相同或更少信息。紧张slow push in每镜5-8s——越慢观众越焦虑。惊吓静态2-3s→突发0.5-1s，落差越大冲击越强。关键线索跨镜完全相同。暗光靠场景资产。

## 五、镜头运动与节奏
「克制」——静止、慢推、极缓pan为主。handheld只用于追逐。zoom in频率低但每次意味「注意这个」。惊吓公式：静2-3s→突切0.5s→留白1-2s。反转：对切加速后关键台词处留1-2s CU静默让情绪沉降。

## 七、变体类型适配
- 心理博弈：对白50%沉默间隙1-2s，CU停留4-6s MCU为主不过肩
- 惊悚恐怖：远景空镜20%，惊吓2-3次后5-8s恢复期

## 八、常见误区
- 故意含糊——好悬疑是信息隐藏而非不存在，事后能复盘所有线索
- 惊吓缺静默前奏——跳吓前安静至少2-3s
- 用台词解释案情——真相应视觉序列拼凑，台词只做最低限度引导

## 红线
- 禁「气氛紧张/诡异/毛骨悚然」等抽象词
- 禁写光影/色调表达恐怖
- 惊吓每element 1-2次
- 关键线索须视觉可识别
