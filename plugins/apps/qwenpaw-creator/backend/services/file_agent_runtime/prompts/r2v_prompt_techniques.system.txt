# R2V Prompt 技术参考

本文件为 R2V 生成导演专用技术参考，定义镜头景别映射、运镜词汇、角色位置标注规则和参考图绑定格式。

## 1. 镜头景别映射

| 景别（Shot Scale） | 中文名称     | 视觉范围                         | 适用场景                   |
|--------------------|--------------|----------------------------------|----------------------------|
| ECU / Extreme CU   | 极特写       | 单一细节（眼睛、手指、唇）       | 情绪爆发、关键道具揭示     |
| CU / Close-up      | 特写         | 面部/单个物体占满画幅            | 对话反应、情感表达         |
| MCU / Medium CU    | 中近景       | 胸部以上                         | 单人对话、内心独白         |
| MS / Medium Shot   | 中景         | 腰部以上                         | 双人互动、动作起始         |
| MLS / Medium LS    | 中全景       | 膝盖以上                         | 站立对话、轻微动作         |
| FS / Full Shot     | 全景         | 全身                             | 出场亮相、姿态展示         |
| LS / Long Shot     | 远景         | 角色占画幅高度 1/3 左右          | 环境交代、角色与环境关系   |
| VLS / Very LS      | 极远景       | 角色极小、环境为主               | 大场景建立、氛围渲染       |

## 2. 运镜词汇

| 运镜词                   | 含义                                 | 用途                         |
|--------------------------|--------------------------------------|------------------------------|
| push in / dolly in       | 镜头匀速向前推进                     | 强调情绪、聚焦角色           |
| pull back / dolly out    | 镜头匀速向后拉远                     | 揭示环境、缓解紧张           |
| pan left / pan right     | 镜头水平摇动（机位不动）             | 跟随主体移动、展示环境       |
| tilt up / tilt down      | 镜头垂直摇动                         | 揭示上下关系、主体站立      |
| track left / track right | 镜头平行跟随主体移动                 | 步行跟随、并行动作           |
| orbit / arc              | 镜头环绕主体半周或一周               | 360°展示、仪式感            |
| boom up / boom down      | 镜头升降                           | 视角高度变化、权力关系表达   |
| handheld / steadycam     | 手持感（微晃）/ 稳定器（平滑）        | 纪实感（追逐）/ 流畅（漫步）|
| static                   | 固定机位                             | 对话、观察、稳定叙事         |
| zoom in / zoom out       | 变焦推拉（机位不动）                 | 主观聚焦、情绪抽离           |

## 3. 角色位置/朝向标注规则

### 3.1 画面位置坐标系

使用以下相对术语描述角色在画幅中的方位：

x轴（横向）：左边缘（left frame）→ 左中（center-left）→ 中央（center）→ 右中（center-right）→ 右边缘（right frame）
y轴（纵向）：前景（foreground）→ 中景（midtone）→ 背景（background）

组合示例：`左前（foreground-left）`、`中央偏右中景（center-right midtone）`。

### 3.2 朝向标注

以画布方向为参考系，非角色自身左右：

- `面朝镜头（facing camera）`：角色正面朝向观众
- `面朝左/面朝右（facing left/right）`：角色侧对镜头
- `背对镜头（facing away from camera）`：角色背面朝向观众
- `四分之三侧（3/4 profile）`：介于正面与侧面之间

### 3.3 多人场景标注

多人场景时每人标注格式：`[角色名]：{位置}, {朝向}`

示例：
```
人物A：左前（foreground-left），3/4 面朝内部
人物B：中央偏右中景（center-right midtone），面朝左（与 A 对视）
人物C：右后背景（background-right），背对镜头远眺
```

### 3.4 跨镜头连贯性

同一 element 内多个 shot 间：
- 除非 Shot 描述明确标注转角/位移，否则保持角色位置与朝向不变。
- 角色转向必须伴随明确触发事件（如听到呼唤转头）。
- 位置跳跃仅允许在两个 shot 存在明显时间间隔（cut）或场景切换时。

## 5. 分镜间过渡与连贯性设计

video prompt 中多镜之间的过渡需遵循以下四类桥接规则，消灭片段切换时的跳跃感。

### 5.1 动作的桥梁

前后两镜描述同一组人物的连续动作时适用。

原则：前镜结尾必须是动作的"起始态"，后镜开头必须是该动作的"进行时"或"完成时"。禁止让动作在片段边界"冻结"然后"跳转"。

```
错误：前镜结尾"他握紧剑柄。" → 后镜开头"他拔剑冲上前。"
正确：前镜结尾"他的手猛地握住剑柄，指节泛白。" → 后镜开头"利剑嗡一声出鞘，剑身映出面部侧影。"
```

### 5.2 情绪的接力

对话或冲突场景中情绪在镜边界延续时适用。

原则：前镜结尾通过反应镜头、微表情或肢体细节为下一镜的情绪爆发/转折做铺垫。后镜开头承接此铺垫进行强化或反转。

```
正确：前镜结尾"特写她说完后紧抿的嘴角和瞬间泛红的眼眶。" → 后镜开头"他看着她强忍泪水的脸，喉结滚动，最终挫败地垂下眼。"
```

### 5.3 空间与视线的链接

对话结束后切换到另一场景，或视线在人物间转移时适用。

原则：利用空镜、视线引导、声音元素建立空间联系。用一个人物的视线引出下镜的空镜，或用延续的环境音连接两个空间。

```
正确：人物愤怒地看向窗外 → 窗外暴雨敲打玻璃的空镜（雨声延续） → 淡入至次日喧闹街市全景
```

### 5.4 台词与动作的黏合

前镜的台词/音效需要在下镜得到画面回应时适用。

原则：音画跨镜同步。前镜末尾的声音（台词关键词、摔门声等）延续到下镜首镜中，由下镜画面来承接这个声音。

```
正确：前镜结尾"话音落下，咚的一声沉闷撞击。" → 后镜开头"特写地上一只青花瓷碗，还在微微打转。"
```

## 4. 参考图绑定格式

### 4.1 绑定语法

prompt 正文中使用 `@图N` 标注将角色/场景/道具绑定到参考图：

```
@图1 林夏穿着 @图2 红色围巾站在 @图3 老城区街角
```

对应的 `reference_version_ids[]` 中第 N-1 项为图 N 的 AssetVersion ID：
```json
"storyboard_reference_version_ids": ["vid_001", "vid_002", "vid_003"]
```

### 4.2 主次参考层级

| 层级 | 用途               | 内容                   | 位置                     |
|------|--------------------|------------------------|--------------------------|
| 主   | 风格与场景基准     | storyboard output      | refs[0] / @图1           |
| 次   | 角色/道具单体参考  | visual entity 对应版本 | refs[1..] / @图N (N>=2)  |

### 4.3 注意事项

- 每张参考图在 prompt 中至少被 @ 引用一次，无引用图不应出现在 reference_version_ids 中。
- 同一实体在多个参考图中出现时，取质量最高（正面、清晰、光照均匀）的那个版本。
- storyboard output 作为主参考时，在 prompt 开头声明：`以 @图1 storyboard 构图和色调为准`。
