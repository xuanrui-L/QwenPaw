# QwenPaw Creator

QwenPaw Creator 是一个 **Agentic 视频创作平台**：你只需要把目标、素材和限制交给 Agent，剩下的策划、生成、剪辑、合成都由 Agent 像一支制作团队一样协同完成。Agent 贯穿创作全程——它会扮演编剧、导演、视觉开发、动效师、剪辑师等专家角色，拆解你的创作目标、逐步产出内容，并在每个关键节点等待你的审阅与确认；而你随时可以用一句话介入，调整创作方向。

Creator 既能**从零生成**（如短剧：剧本 → 资产 → 分镜 → 视频），也能**基于已有素材剪辑成片**（素材理解 → 时间线编排 → 字幕/动效/转场 → 合成）。无论是从一句想法开始，还是从一批现成素材开始，都可以交给 Creator 完成。

## 快速开始

### 打开 Creator

Creator 是 QwenPaw 中的一个应用（App）。启动 QwenPaw 后打开控制台（默认 `http://127.0.0.1:8088/`），在左侧导航进入 **Apps（应用中心）**，点击 QwenPaw Creator 即可进入创作平台。

![在 QwenPaw 应用中心打开 Creator](/docs/images/creator/app-entry.png)

### 配置模型

首次使用前，点击首页输入框旁的 **模型配置**（或按引导提示）完成模型接入。不同创作场景需要的模型不同：

| 创作场景         | 需要配置的模型                                  |
| ---------------- | ----------------------------------------------- |
| 所有场景         | 大语言模型（LLM）                               |
| 短剧等生成类创作 | 图片生成模型、视频生成模型、视觉语言模型（VLM） |
| 上传素材剪辑     | VLM（用于素材理解）                             |
| 含人声素材       | 语音识别模型（ASR）                             |

当前支持的模型提供商：

| 能力      | 支持的提供商                                                            |
| --------- | ----------------------------------------------------------------------- |
| LLM / VLM | OpenAI 协议、百炼、Claude、DeepSeek、Gemini、千帆、火山引擎、自定义     |
| 图片生成  | OpenAI 协议、百炼                                                       |
| 视频生成  | 百炼（wan2.x r2v、happyhorse-1.x-r2v）、火山引擎（doubao-seedance-2.x） |
| ASR       | Fun-ASR、Whisper                                                        |

### 创建第一个项目

在首页把你的创作意图交给 Agent：

1. **描述目标**：例如「霸道总裁短剧，要突出快节奏，强化戏剧冲突，最后要有个美好结局」，或「帮我剪辑一个 1 分钟左右的猫咪精彩视频合集」；
2. **提供素材**（可选）：通过「添加文件 / 添加文件夹 / 添加链接」导入视频、图片、文档等参考资料，进入项目后它们会成为可管理、可引用、可追踪的项目资产；
3. **选择创作类型与规格**：短剧 / 剪辑 / 通用（口播、图文成片等其他形态可用通用类型 + 目标描述实现），并选定分辨率与画幅（如 720P、16:9）；
4. 点击发送，Agent 随即开始策划并进入创作工作台。

## 创作工作台

进入项目后，你会看到 Creator 的核心界面——**视频方案** 工作台。Agent 产出的所有内容都在这里被结构化地呈现和编排：

![视频方案工作台](/docs/images/creator/workbench.png)

- **创作总纲**：项目的整体方案与成片信息（总时长、分辨率、画幅、内容项数）；
- **时间轴**：多轨道呈现成片结构——素材剪辑、字幕、动效、转场各占一轨，拖动时间轴可定位到任意时刻；
- **时间点内容**：左下列表列出当前时刻命中的所有内容项（类型、时间范围与简介），方便确认同一时刻的画面、字幕与动效是否对齐；
- **详情面板**：点击任意片段（时间轴上或左侧列表）展开其详情，可查看和编辑开始时间、持续时长、叠放层级、成片画面位置与不透明度等参数，修改后点击「应用修改」生效；
- **资产库**：顶部切换到资产库，可浏览项目内的全部素材与生成产物（角色图、场景图、分镜图、视频片段等）；
- **创作助手**：右侧面板是与 Agent 对话的入口，实时展示制作流程的每一步（构思、委派 Specialist、生成、更新方案），你可以随时输入修改意图。

### 与 Agent 协作

创作助手是贯穿全程的协作入口，几个实用技巧：

- **@ 引用对象**：输入 `@` 可引用分镜、素材等对象作为上下文；当前选中的对象也会自动带入对话；
- **随时干预**：无论 Agent 正在策划还是生成，你都可以直接下达新指令（如「把第二个片段的文案改成……」），Agent 会读取当前项目状态后做出关联修改；
- **即时停止**：执行中的任务可通过停止按钮立刻中断。

## 两种典型创作方式

### 短剧生成：从零到成片

对于生成类创作，Agent 会按以下流程逐步推进，每一步的产出都是下一步的输入：

```
剧本 → 分镜文本 → 资产生成（角色锚点图 + 场景基准图）→ 分镜图 → 视频 → 合成
```

1. **剧本与分镜**：Agent（编剧/导演角色）根据目标生成剧本，并拆解为结构化分镜（场景、角色、动作、台词）；
2. **资产生成**：视觉开发 Specialist 先为每个角色生成锚点形象图、为每个场景生成基准图——这是保证全片角色与场景一致性的关键前置步骤；
3. **分镜图**：以资产图作为参考输入，逐镜生成分镜画面；
4. **视频生成**：基于分镜图与资产图，调用参考生视频（r2v）模型逐镜生成视频片段；
5. **合成**：所有片段就绪后自动合成完整成片。

每一步的产物都会进入审阅流程等待你确认，例如角色形象图生成后：

![角色资产图审阅](/docs/images/creator/asset-review.png)

### 素材剪辑：从素材到成片

对于剪辑类创作，把原始素材交给 Agent 即可：

1. **素材导入与理解**：Agent 借助 VLM（含人声时结合 ASR）逐段理解素材内容，识别精彩瞬间；
2. **剪辑方案**：Agent（剪辑角色）挑选片段、编排时间线，并按需要补充字幕、动效、转场；
3. **精修**：你可以在时间轴上点击任意片段直接调整，也可以让 Agent 代劳（如「开场加一组阳光射线装饰动效」）；
4. **合成**：确认方案后合成成片。

## 审阅与成本控制

Agent 的每一处改动都在你的掌控之中。

### 内容审阅

- Agent 生成或修改的**图片与视频**都会进入审阅队列，「保留」采纳、「撤销」回退，支持逐条处理或全部保留/撤销；
- Agent 干预产生的**文本修改**以红/绿 diff 展示改动前后对比，点击「查看」可跳转到原文位置比对；
- 审阅项支持精准跳转到生成上下文（角色图 → 资产详情、分镜图 → 分镜详情、视频 → 视频生成详情）；
- 你**手动修改**的内容默认直接生效，不占用审阅流程。

![文本修改 diff 审阅](/docs/images/creator/text-review.png)

### 生产确认（费用预估）

调用付费生成模型（图片/视频生成）前，Agent 会先弹出**生产确认卡**：列出操作对象、所用模型、参数与提示词，并给出本地计算的预估费用。点击「继续」才会真正提交计费任务，「取消」则终止本次制作；也可在模型配置中关闭此确认。

![生产确认与费用预估](/docs/images/creator/execution-auth.png)

> 💰 预估费用按各模型官网单价本地估算，仅供参考，实际费用以服务商账单为准。

## 附录：安装与运行环境

Creator 目前以应用包的形式随 QwenPaw 分发，在 QwenPaw 离线时执行安装，重启后即出现在应用中心：

```bash
qwenpaw plugin install /path/to/qwenpaw-creator
```

Creator 依赖若干本地工具（不会改动系统安装）：`ffmpeg` 负责媒体处理与成片合成（可用 `CREATOR_FFMPEG_PATH` 指定，否则回退系统 `ffmpeg` 或 `imageio-ffmpeg`）；`jq` 支撑 Agent 对项目文件的结构化编辑（`CREATOR_JQ_PATH` 或 `PATH`）。依赖缺失时 Creator 以降级模式启动，可通过 `GET /api/qwenpaw-creator/health` 查看缺失项。
